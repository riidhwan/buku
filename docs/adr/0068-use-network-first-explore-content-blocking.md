# Use network-first Explore Content Blocking

Explore Content Blocking starts as an always-on, conservative WebView resource interception policy in the native Explore Browser, backed by a small repo-owned bundled blocklist, third-party cookie blocking, and only minimal cosmetic cleanup for obvious empty ad containers. This favors blocking common third-party ad and tracker resources before they run while avoiding browser-extension parity, full public filter-list parsing, runtime rule downloads, aggressive first-party filtering, user-managed rules, visible blocked-request telemetry, and site-specific anti-adblock bypassing that would turn Explore into a general-purpose ad blocker. If blocking breaks a site in v1, the recovery path is the existing external-browser handoff rather than per-site allowlisting or a settings surface.
